Heroes 3 HotA Companion
=======================
Interactive atlas for Heroes of Might and Magic III: Horn of the Abyss maps,
with savegame import. Pick any .h3m from your install on the start screen.

Run
  Windows: unzip, start "Heroes 3 HotA Companion.exe"
  Linux:   unzip, run ./"Heroes 3 HotA Companion"

Saves
  The app looks for your Heroes 3 install (Data, Maps) and "Games" folder
  automatically (GOG, Steam HD, common HotA install paths, Bottles/Wine on
  Linux). If nothing is found, use the folder buttons on the start screen or
  the File menu (the saves folder is scanned two levels deep, e.g.
  "- The Mysterious Island -").

Everything runs locally; no file leaves your machine.
