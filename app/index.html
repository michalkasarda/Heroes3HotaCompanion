The Mysterious Island

HotA v1-5-j, 252x252, two levels. Gold = artifact on the ground, red = random artifact, cyan = reward (Seer's Hut, guard, Pandora, bank, corpse, prison). Coordinates match the editor.

Enter = next

        Load a save and pick your colour: this lists every combination artifact, which parts your heroes already carry (equipped or in the backpack, including heroes inside towns), and where the missing parts lie on the map.

        Left-click the map to set the start, right-click to set the goal; the route redraws whenever both are set. Or use a town / an artifact's → button. Cost uses H3 movement points: road 50–75, dirt/grass/lava/subterranean 100, rough/wasteland 125, sand/snow 150, swamp 175, diagonal ×1.41. Routes may pass through any object entrance (towns, dwellings, shrines, garrisons, gates, monoliths, subterranean gates), since a hero stands on the entrance tile and can leave it in any direction. The report lists what blocks the way.
